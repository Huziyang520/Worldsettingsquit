# World Settings Quick Exit (世界设置便携退出)

> Press ESC in the world options screen to apply changes and exit · Minecraft 26.3 · Fabric + NeoForge

---

## English

### What it does

When you open the **World Options** screen in a world and change a setting, vanilla requires you to click "Apply Changes" before leaving. This mod merges the two steps: **pressing ESC is the same as clicking "Apply Changes" and closing the screen**.

- Pressing ESC **with changes** applies them, then closes the screen.
- Pressing ESC **without changes** behaves like vanilla (returns directly).
- Clicking **Cancel** keeps its original meaning and still discards your changes.
- When locking the difficulty, pressing ESC shows the vanilla confirmation popup first, then applies and exits after you confirm.

### Compatibility

| Item | Value |
|---|---|
| Minecraft | 26.3 (`[26.3, 26.4)`) |
| Loaders | Fabric Loader `0.19.5` / NeoForge `26.3.0.1-beta` |
| Java | 25 |
| Side | Client only |
| Dependency | **KeenLib ≥ 0.1.0** (required) |

Install **KeenLib** first, then put this mod's jar for your loader into the instance `mods` folder:

- Fabric: `worldsettingsquit-0.2.3-fabric-26.3.jar`
- NeoForge: `worldsettingsquit-0.2.3-neoforge-26.3.jar`

## 中文

### 功能说明

在原版世界里打开**世界设置**界面修改设置后，原版需要先点击「应用更改」才能生效。本模组把这两步合并：**按 ESC 等同于点击「应用更改」并关闭界面**。

- **有修改时按 ESC** → 应用全部未保存的更改，然后关闭界面。
- **无修改时按 ESC** → 与原版一致，直接返回。
- **点击「取消」按钮** → 语义保持不变，仍然放弃本次修改。
- **锁定难度时** → 按 ESC 会先弹出原版的确认弹窗，确认后再应用并退出。
